# Simple Farmland Protection

![Minecraft](https://img.shields.io/badge/Minecraft-26.3-brightgreen)
![ModLoader](https://img.shields.io/badge/ModLoader-Universal-purple)
![Side](https://img.shields.io/badge/Side-SERVER-success)

Say goodbye to accidental crop trampling!

* Safe base fall distance up to 1.51 blocks (e.g. falling from a fence will not trample farmland).
* Falling from greater heights will trample farmland.
* Small entities (baby mobs, rabbits, chickens, etc.) will never trample farmland.
* Mobs respect the `mob_griefing` game rule.
* Each level of Feather Falling on boots increases safe fall distance by +2.0 blocks.
